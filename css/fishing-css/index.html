CSS Fishing Game

This game is a peaceful, quiet game where you are fishing in a vast ocean. There is no fishing meachinisms built into this prototype of the game, so it is mainly an experimentation of how the movement, animations, and visuals play out in a game.

Controls

Keyboard

  • Hold ⬅︎ to move left
  • Hold ⮕ to move right
  • Tap Space to cast line

Touch Screen

  • Hold Left button to move left
  • Hold Right button to move right
  • Tap Cast button to cast line

Pixel Lacework Drawer

This pixel drawer allows you to create a pixel lacework doily design! You can either create your own, or look through the designs I have created using this program. You can also save your designs, and come back to them anytime using the code!

Controls

Keyboard

  • When prompted, type:
    • compare to compare the designs that I have made in the program
    • (a number)*(a number)*(0, 1, or 2) to create a blank canvas width the width as the first number, the height as the second number, and the color as the third number
    • a previous design's code that you saved beforehand (see it on the lefthand side of the lacework)
  • Tap 0 to change the color to black
  • Tap 1 to change the color to gray
  • Tap 2 to change the color to white
  • Tap a pixel to change its color
  • Copy the code in the top left and save it in order to save your code — just paste it back into the prompt
  • Make a code immutable by changing the first digit in the code to a 1, or make it mutable by changing it to a 0
  • Tap ⬅︎ to scroll to previous design if in compare mode
  • Tap ⮕ to scroll to next design if in compare mode
  • Tap ⬆︎ or ⬇︎ to change the design from light to dark if in compare mode

Touch Screen

  • When prompted, type:
    • compare to compare the designs that I have made in the program
    • (a number)*(a number)*(0, 1, or 2) to create a blank canvas width the width as the first number, the height as the second number, and the color as the third number
    • a previous design's code that you saved beforehand
  • Tap black button to change the color to black
  • Tap gray button to change the color to gray
  • Tap white button to change the color to white
  • Tap a pixel to change its color
  • Copy the code in the top left and save it in order to save your code — just paste it back into the prompt
  • Make a code immutable by changing the first digit in the code to a 1, or make it mutable by changing it to a 0
  • Tap ← button to scroll to previous design if in compare mode
  • Tap → button to scroll to next design if in compare mode
  • Tap ↺ button to change the design from light to dark if in compare mode
